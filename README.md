## 💡 方案核心逻辑速览

### 1. 业务痛点与现状
- **渠道结构失衡**：谷雨 2024 年 GMV 突破 50 亿元，线下布局超 30,000 家专柜与合作终端，但线上营收占比约 93%，实体门店缺乏数字化体验抓手；
- **售前缺乏耐受筛查**：年轻消费者兼具“美白诉求高”与“屏障耐受脆弱”的双重特征，售前缺乏科学评估导致盲买致敏，退货与客诉集中；
- **重硬件模式不可行**：大型专业测肤仪器单台成本数千元且维护复杂，无法在 3 万家门店规模化普及。

### 2. 系统方案设计
- **前端严格质检（IQA）**：“不过质检不测肤”，端侧实时拦截光线不均、手抖模糊与浓妆遮挡，确保输入数据真实可靠；
- **图文多模态互补**：视觉模型专注表皮色彩计算（$L^*, a^*, b^*, ITA^\circ$），3 道自述问卷锁定屏障敏感史与出油规律，交叉消除误判；
- **克制的产品履约**：基于谷雨真实产品线，向用户仅推荐针对性的“1 瓶功效液态 + 1 款屏障面霜”最小必要组合，附带 28 天生理周期见效预期管理；
- **线上线下全域闭环**：线上自测生成去人脸化的“光合肤质档案卡”激发社交自发分享，同时引流至线下门店领样复测；专柜 BA 借助企业微信提词卡提供标准化咨询，测肤数据沉淀至私域。

### 3. 单店财务与成本
- **低成本标准化物料**：单店配备高显色补光灯、固定支架与 24 色微型校色贴片，综合硬件成本约 150~200 元/店；
- **回本周期敏感性测算**：以单店月均 900 人进店客流模型测算，成交转化率绝对值仅需提升 1.5%（每月增售约 2.7 单），当月即可完全收回硬件物料投入。
