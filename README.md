## 💡 当前核心方案思路速览：方向 B（线下专柜双轮驱动）

### 1. 核心痛点与洞察
- **谷雨资产现状**：2024 年 GMV 破 50 亿，拥有全国 **30,000+ 家线下专柜/网点**，但营收 **93% 依然依赖线上**，线下坪效偏低。
- **专柜终端痛点**：
  1. **BA（导购）专业度参差不齐**：面对高要求的“成分党”和敏感肌顾客，容易凭经验推销、夸大美白功效，导致“泛红刺痛、28天无效果”客诉退货。
  2. **到店顾客即买即走**：线下体验场景单一，顾客与品牌缺乏深度互动，无法沉淀到长效私域。
  3. **硬件投入壁垒高**：不能走资生堂 Optune 等重硬件失败的老路（动辄数千元专业测肤设备难以在 3 万门店规模化铺设）。

### 2. 方案核心架构：“轻硬件 + 双端协同 + 私域长效闭环”
- **低成本交互硬件**：专柜配备标准防抖/校准补光手机支架或平板电脑（单店成本 < 150 元）。
- **C 端（顾客轻量测肤小程序）**：
  - 3 秒标准化人脸自拍（姿态与光线自检引导，吸取 Nature 子刊 AcneDGNet 经验）；
  - 基于谷雨自有 **5 万动态样本数据库与 18 项中国人肤质指标**，生成“黄气值、泛红值、光泽度”可视化雷达图；
  - 给出针对性“最小必要组合”推荐（吸取 OLAY 经验，拒绝大套盒推销）。
- **B 端（专柜 BA 智能 Agent 提词器）**：
  - 基于谷雨科研知识库与 RAG 检索生成，实时为 BA 提供合规、严谨的成分机理解释与敏感肌适配预警；
  - 消除“虚假夸大宣称”，提升成单转化率与顾客信任度。
- **私域闭环（28 天光合美白追踪计划）**：
  - 测肤结果一键沉淀至企业微信私域；
  - 引入国际标准肤色分级角 $ITA^\circ$ 动态曲线追踪，用微小客观改善量化对抗“见效慢、中途放弃”痛点（借鉴欧莱雅 Brandstorm 冠军 REVIX 经验）。
