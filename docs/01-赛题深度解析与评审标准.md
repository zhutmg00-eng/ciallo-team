## 二、 评委到底看重什么？（顶级商赛获奖逻辑拆解）

通过对欧莱雅 Brandstorm（历届中国区及全球冠军）、美妆科技黑客松、挑战杯揭榜挂帅特等奖、三创赛等 24 个真实获奖项目的深度复盘，我们提炼出评委评分的底层模型：

$$\text{顶级得分} = \text{极具共鸣的真实痛点} \times \text{恰到好处的落地技术} \times \text{严密闭环的商业测算} \times \text{不可替代的品牌咬合度}$$

### 1. 痛点必须真实具象（拒绝“空中楼阁”）
- **错误做法**：写大而泛的宏观痛点（“当代年轻人容易焦虑、皮肤不好”）。
- **制胜做法**：有明确的具象人物和真实场景（Persona）。
  - *案例参考*：2025 欧莱雅中国冠军 DARKLION 从“队员父亲染发反复冒白发且脱发”切入；REVIX 团队从“男性买眼霜坚持不到 7 天就放弃”切入。
  - **谷雨赛题切入**：从“3万家门店导购说敏感肌可用但顾客用了过敏”、“顾客用了28天肉眼看不出变白愤而退款”等真实客诉痛点切入。

### 2. 技术要“刚好够用、极高可行性”（拒绝“虚幻炫技”）
- **错误做法**：宣称“自研全脑神经脑电波仪”、“全息量子护肤机器人”或昂贵的定制硬件设备（如资生堂 Optune 惨败案例）。
- **制胜做法**：成熟技术的高效组合（手机/Pad 摄像头 + 计算机视觉自检 + 现有大模型 RAG 知识库检索 + 企业微信私域连接），并在方案中展示清晰的数据流图和系统架构。

### 3. 商业模式与 ROI 必须“算得过账”
- 评委一定会问的三大灵魂拷问：
  1. **这套方案单店/单用户部署成本是多少？**
  2. **能带来多少增量转化率？客单价与复购率提升多少？**
  3. **凭什么谷雨做能成，别人做不行？（壁垒是什么？）**

### 4. 品牌咬合度（必须接得住谷雨的原生资产）
- 方案不能换个“珀莱雅”或“薇诺娜”的标照样能用。
- 必须深度捆绑谷雨的独特优势：
  - **5 万人动态大样本数据库 + 18 项中国人肤质指标模型**；
  - 独创的 **“黑、黄、红”肤色问题分型**；
  - 核心成分 **光甘草定**（28nm 纳米包裹靶向渗透技术）；
  - 全国 **30,000+ 家线下专柜/终端门店网点**。

## 三、 推荐方案结构（PDF 骨架标准建议）

一份标准且极具杀伤力的 15~20 页商业方案 PDF 结构：

1. **封面 & Executive Summary（1页）**：一句话痛点 + 一句话解法 + 3个核心商业预期数字（ROI、转化率、复购率）。
2. **痛点与市场洞察（2-3页）**：宏观行业数据 $\rightarrow$ 谷雨真实客诉/渠道痛点 $\rightarrow$ 典型用户画像与使用场景。
3. **解决方案与服务蓝图（3-4页）**：
   - 整体架构图与服务闭环（采集 $\rightarrow$ 诊断 $\rightarrow$ 推荐 $\rightarrow$ 执行 $\rightarrow$ 追踪）；
   - C 端顾客轻量交互体验流程；
   - B 端门店导购赋能流程。
4. **核心技术架构与可行性佐证（3-4页）**：
   - 视觉测肤算法管线（拍摄质量控制 + 谷雨18指标映射）；
   - 知识库与 RAG 导购生成管线；
   - 原型界面展示（Figma 效果图 / 视频截图二维码）。
5. **商业模式与财务测算（2-3页）**：
   - 成本结构测算（硬件成本、云端推理/调用成本）；
   - 收入与收益预估（成单率提升、退货率降低、私域留存价值）；
   - 试点推广路线图（MVP $\rightarrow$ 100家标杆店 $\rightarrow$ 全面推广）。
6. **风险防范与法律合规（1-2页）**：
   - 《个人信息保护法》（PIPL）敏感人脸信息保护合规架构；
   - 化妆品功效宣称边界合规（“护肤建议” vs “医疗诊断”严格界定）。
7. **团队介绍与总结（1页）**：队员学科交叉优势与项目愿景。
