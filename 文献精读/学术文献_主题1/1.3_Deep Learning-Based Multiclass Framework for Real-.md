# Deep Learning-Based Multiclass Framework for Real-Time Melasma Severity Classification

- **ID / 序号**: 1.3
- **类别**: 03_学术文献 / 学术文献_主题1
- **URL**: https://pmc.ncbi.nlm.nih.gov/articles/PMC12049110
- **网页标题**: Deep Learning-Based Multiclass Framework for Real-Time Melasma Severity Classification: Clinical Image Analysis and Model Interpretability Evaluation - PMC
- **作者/机构**: Zhang J 等（武汉市第一医院）
- **期刊/年份**: Clin Cosmet Investig Dermatol (CCID) (2025)

## 资料包原生注释
- **核心结论/摘要**: 1,368 张黄褐斑图像，由 3 名医生按 MASI 评分取均值作为标签。GoogLeNet 表现最好，准确率 0.755，各级 AUC 0.86–0.94，并用 LRP 做了可解释性分析。
- **赛题应用价值**: 证明 AI 可以评估「斑」的严重程度，同时说明准确率只有 75%，提示我们应输出「趋势」而不是「诊断」。
